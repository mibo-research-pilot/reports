# Rights and Licenses

This archival bundle combines materials from three repositories. It does not assign one blanket license to every file.

## Researcher-authored conceptual materials

The `core-context/` snapshot includes its own `LICENSE` (Apache License 2.0). The pinned Core README describes that license as applying to researcher-authored conceptual text, documentation, and validation code. Refer to the included source license and attribution materials.

## Pilot query instrument

The `query-instrument/` snapshot includes its own `LICENSE` (CC0 1.0 Universal). The pinned Queries README states that query sets are released under CC0-1.0 unless otherwise stated. Historical version files and integrity metadata are preserved without modification.

## Observation metadata, coding, and analysis

The bundle includes the pinned Reports `LICENSE` (CC0 1.0 Universal) at `reports-evidence/LICENSE` as a source-specific rights document. It is not one of the 21 evidence paths selected by the existing Paper B hash manifest and is separately protected by the outer manifest. The pinned Reports README states that observation data and query sets are released under CC0-1.0 unless otherwise stated. This release metadata records that source statement without extending it to material for which the researcher does not control rights.

## Model-generated responses

Some observation reports embed model-generated text. The pinned Reports README states that raw model outputs remain subject to applicable provider terms. This bundle does not grant additional rights in those outputs and does not represent that public GitHub visibility establishes unrestricted redistribution rights.

## Third-party and provider-derived material

URLs, source titles, product and organization names, quotations, citation-like traces, and other third-party material remain subject to any applicable rights of their owners. Their preservation here is evidentiary and does not transfer ownership or create a new license.

## Publication review status

No evidence has been deleted because its rights status is unclear. Before Zenodo publication, a human rights review should confirm that redistribution of embedded model-generated and third-party material is compatible with applicable provider terms and research-use requirements. This is an unresolved publication review item, not a claim that a violation has been found.
