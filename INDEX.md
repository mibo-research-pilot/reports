## Verification rule

A session is included in verified cumulative counts only when:

1. the expected responses or explicit error records exist;
2. included and excluded systems are stated;
3. observation-level coding has been reviewed;
4. provenance anomalies are documented;
5. the narrative report has been completed;
6. cumulative counts reconcile with the preceding verified session.

A filename or scaffold alone does not make a session verified.
